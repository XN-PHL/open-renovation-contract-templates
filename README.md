# 住宅室内装修施工合同模板

**v0.1.0｜简体中文｜CC BY 4.0**

版本说明：通用首版，拆开报价边界及不同计价方式，补上装修增项签证、分工种验收、付款、退出和保修。

本仓库提供可编辑、可搜索的中国大陆住宅装饰装修合同模板。支持旧房翻新、半包、清包和按清单全包；不是政府示范合同，不替代对当地法规、现行标准、产权和施工条件的核验。

- [合同正文和 A–H 附件 Markdown](contract.zh-CN.md)：浏览、检索、复制、比较版本。
- [可编辑 Word 模板](contract.zh-CN.docx)：与 Markdown 同文，可填写与打印。
- [许可及署名说明](NOTICE.md)、[标准许可原文](LICENSE)、[文件 SHA-256](MANIFEST.sha256)。

使用时先确认施工、收款及保修主体；再填写报价范围、包干与实量界线、暂估上限、开工与交付条件；施工中变更先签、隐蔽覆盖前验，并将设备交接、尾款和缺陷留款分别记录。

## 官方规则核验入口

- [《中华人民共和国民法典》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_60fb3863b7364b759123a42d1df568ca.html)：格式条款、合同解除和违约、承揽与建设工程。
- [《住宅室内装饰装修管理办法》](https://www.mohurd.gov.cn/gongkai/zhengce/gzk/art/2022/art_17337_763893.html)：登记、装修限制、厨卫防水、验收与保修。
- [《中华人民共和国消费者权益保护法实施条例》](https://app.www.gov.cn/govdata/gov/202403/19/513111/article.html)：预付款规则。
- [《合同行政监督管理办法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_7bcc7ff64200464daeb4b87ce450592f.html)：经营者提供格式条款的限制。

其他地方规则、项目技术标准及产品验收要求由双方结合实际确定。链接内容不计入本模板的授权范围。
